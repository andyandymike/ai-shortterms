## 现场怎么用

1. 打开观众页，点击底部 **Presenter ↗**，由它打开同步的讲者窗口。
2. 观众页放到投影，讲者窗口留在自己的屏幕。口播和下一步提示只在讲者窗口出现。
3. 讲完当前内容，按 **下一步 / Continue**。该播放的动作会自动完成，到下一个讲解点停住；需要翻页、换章节时，同一次操作会一起完成。
4. 等动作完成，看看当前结果，再讲对应口播。讲者窗口会告诉你目前停在哪里、下一次点击会发生什么。

整场是 21 页、42 个讲解点的一条顺序。无需另找 Play，也不用提前记熟哪一次该翻页。提交与截图验证连成一段；Blender 首次预览与修正保留停顿。C7、J5、R6 各用三个停点解释练习、参数更新与独立检查。排序只保留 A、B、C 三次运行，每段自动检查。

动画中，主按钮会变为「暂停动画 / Pause」；暂停后变为「继续播放 / Resume」，仍然控制当前这一段。到达讲解点后，才重新成为「下一步 / Continue」。因此需要多讲一会时，停在讲解点即可，不会自己翻页。

讲者窗口由观众页创建连接。重新开始或打开另一场演示时，也从对应观众页打开 Presenter，避免控制到其他窗口。

## 演示控制

| 操作 | 结果 |
| --- | --- |
| 主按钮 / Space / → / Page Down / N | 停顿时进入下一个讲解点；动画中暂停；暂停后继续当前段 |
| 上一步 / ← / Page Up | 返回前一个讲解点，并显示那里的完成画面 |
| 重播当前段 / R | 重新播放当前讲解段 |
| 讲者窗口：直接看结果 | 直接完成当前段，到达它的讲解停顿点 |
| 底部章节名 / 页内进度轨道 | 直接跳到相应章节或页面 |
| 观众窗口：Home / End | 开场 / 收束 |
| 观众窗口：S / Sources | 查看当前章节的一手来源与示例边界 |
| Escape | 关闭来源弹窗 |
| 最后一页主按钮 | 返回两场目录 |
| 左下 AI / FIELD NOTES | 返回两场目录 |

章节末尾继续就会进入下一章，不会突然重播。影片也由同一个主按钮暂停或续播。讲者窗口中的播放状态与观众页同步。

## 讲稿与画面的对应

只有「说 / SAY」与「转 / TRANSITION」是口播。「画面」「自动动作」「下一次继续」是给讲者看的提示。转场只出现在本页最后一个讲解点，说完再继续。

三个讲稿与讲者窗口共用同一份双语内容。每个编号对应同一个画面停顿点，中英版本的事实、例子、数字和结论范围一致。实际演讲选择一种语言，不需要两遍都读。

叙述顺序是：先让观众看清问题，在指定位置预测，继续后观察变化，再解释结果。比如 C5 先停在旧截图导致的失败，再连续播放重新观察与修正。R4 的 B 运行与检查已合并，停下时直接讨论为什么操作少却被拒绝。

## 现场检查与备选

1. 以常用投影尺寸打开观众页，浏览器缩放为 100%。确认讲者窗口留在自己的屏幕上。
2. 从 C4 连续使用主按钮，确认填表后停住，随后提交与新截图验证连续完成；再进入 C5，确认能看到旧点击失败与新观察带来的修正。
3. 在讲者窗口继续，确认观众页跟着前进；在观众页返回，确认讲者提示也跟着更新。
4. C6 的真实成片会随演示顺序自动播放。影片是本地文件、默认静音；播放失败时显示本地案例静帧。教学动画不是 Blender 运行画面，真实成片也不是鼠标操作录像。
5. 从 C7 看训练与 inference 的区别；从 J2 看 The 与 We 的不同延续；从 J5 看多例反馈、weights 变化与整批新题检查。J6 的混合邮件会直接延续到 J8，不用重新添加问题。
6. 从 R4 走完 A、B、C，确认错误被拒绝、C 被保留；从 R6 检查新配方、loss 与 weights、独立研究任务及下一轮的条件箭头。时间紧时，可用讲者窗口的「直接看结果」到达当前段的停顿点，再继续讲。

所有小实验与图表均无需模型密钥或在线请求。排序候选会在本地真实执行，但候选程序是预先编写的；其他过程是教学示意或已注明来源的例子。来源链接需要网络，本地页面和已打包媒体不需要外网访问。

讲稿与演示共用 `deck/app/session-2/cue-plan.json`。修改口播后运行 `npm run notes:session-2`，同步生成三种语言视图；生成器会核对全部 21 页、42 个讲解点及双语字段。来源与完整事实边界保留在[参考稿](reference.md)。
