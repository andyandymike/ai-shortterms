# 第二场讲稿｜From Answers to Actions

Computer Use → Jev → RSI。独立 Atlas 演示，以约 25 分钟安排排练，含观众观察与 Blender 短片；实际时长随语速与停顿调整。

从观众页底部的 Presenter 打开讲者窗口，把观众页放到投影，讲者窗口留在自己的屏幕。讲者窗口显示当前口播、画面停在哪里，以及下一次点击会发生什么。

## J2 · Choose a token. Change what follows.

[直达本页第一个停顿点](/session-2#jev/J2)

### 17 / 42 · Decoding：选入一个 token，再预测

**画面** The 已加入 context，下一组候选变为 returns 与 support。

**自动动作** 选入 The，停下来观察新候选

**说** Decoding，就是从下一 token 的概率里按规则选一个，加回 context，再预测下一步。Token 可以是一个词、字符或文字片段。刚才选了 The，下一组候选就变成 returns 和 support。前面生成的内容，已经改变了后面的条件。这里的候选和概率都是教学示意。

### 18 / 42 · 换开头，观察后续怎样改变

**画面** 开头换成 We，候选随之改变；We can help . 逐 token 完成。

**自动动作** 改选 We，再自动生成 can help .

**说** 换成 We，后面就适合接 can 或 will，再逐步生成完整句子。每个选入的 token 都会影响下一步。这里自动选最高概率；按概率采样是另一种规则。Decoding 说的就是这一套逐步选取的过程。
